Smart Quiz

Plataforma de Estudo Inteligente para a UniCV

Projeto de Extensão — Equipe UNICV Tech

O cenário que motivou o projeto

📚

Alunos dependem de plataformas genéricas pagas para praticar ENADE, OAB e concursos

🔇

Estudo isolado — sem feedback, sem acompanhamento, sem motivação

📝

Professores criam provas manualmente, sem dados de desempenho

📊

Coordenação sem visibilidade sobre engajamento e dificuldades

“Como transformar a preparação acadêmica em algo engajante, mensurável e acessível para toda a UniCV?”

Três módulos, um ecossistema

🎓
ALUNO

Quiz interativo, feedback imediato, gamificação, ranking

👨‍🏫
PROFESSOR

Banco de questões, montagem de provas, dashboard de desempenho

🛡️
ADMINISTRADOR

Painel de usuários, métricas globais, gestão de conteúdo

5 cursos: Psicologia • Direito • Medicina • Engenharia • Administração

Web + Android + iOS com o mesmo código
